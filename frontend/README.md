# 🚀 Digi Bank – Bank Management System UI

A modern, responsive, and scalable frontend built using:

> **React + TypeScript + Vite + Tailwind CSS + ShadCN UI**

---

## 🧰 Tech Stack

- ⚛️ React 18 – UI Library  
- 🟦 TypeScript – Type-safe JavaScript  
- ⚡ Vite – Lightning-fast build tool  
- 🎨 Tailwind CSS – Utility-first CSS  
- 🧩 ShadCN UI – Accessible component library (Radix + Tailwind)  
- 🔗 React Router DOM – Client-side routing  
- 🛰️ Axios – API communication  
- 🧹 ESLint + Prettier – Code linting & formatting  

---

## 📁 Project Structure

```bash
frontend/
├── api/                  # Axios instance & API handlers
├── components/
│   ├── layout/           # Header, Sidebar, AppLayout
│   └── ui/               # ShadCN-based reusable components
├── hooks/                # Custom React hooks
├── pages/                # Page components like Dashboard, Login
├── routes/               # App routing and auth logic
├── App.tsx               # Root app component
├── main.tsx              # Application entry point
└── index.css             # Tailwind base styles
````

---

## ✨ Features

* 💠 Modular layout with `Header`, `Sidebar`, and `AppLayout`
* 🔐 Private routing using `PrivateRoute` wrapper
* 🌈 Pre-styled ShadCN components: Button, Input, Select, etc.
* ⚙️ Axios setup for clean API abstraction
* 🎯 Strict typing with TypeScript
* 🧼 Consistent formatting with Prettier + Tailwind plugin

---

## 🔧 Getting Started

```bash
# 1. Install dependencies
npm install

# 2. Start development server
npm run dev

# 3. Format code using Prettier
npm run format

# 4. Build for production
npm run build
```
